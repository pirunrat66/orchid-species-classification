# Orchid Species Classification Web Application

This project is a group project focused on developing a machine learning-based web application for orchid species classification. The system was designed to support orchid species identification using data analysis and predictive modeling techniques.

## Project Overview

The project includes dataset preparation, machine learning model implementation, and a simple web application interface for presenting prediction results.

## Tools and Technologies

- Python
- Pandas
- Scikit-learn
- Machine Learning
- Web Application
- Excel Dataset

## Files

- `PROJECT_DATA.xlsx` — Dataset used for the project
- `orchid_decision_tree_v1.pkl` — Trained decision tree model
- `requirements.txt` — Required Python libraries
- `web.py` — Web application script

## Key Features

- Orchid species classification
- Machine learning model implementation
- Simple prediction web interface
- Data-driven species identification support
